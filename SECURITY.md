# Security Policy

## Supported Versions

Bugscope is an actively maintained project. Security updates and patches are only provided for the latest major release. Please ensure you are running the most recent version before submitting a report.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

Thank you for helping improve the security of Bugscope! Because this is a tool designed for security education and research, maintaining the integrity of its own codebase (the Flask dashboard, SQLite database, and proxy engine) is a top priority.

If you discover a security vulnerability within Bugscope, please **do not** open a public issue. We want to ensure vulnerabilities are patched before they are publicly disclosed.

### How to Report
Please report security vulnerabilities directly to the author using one of the following methods:

1. **GitHub Private Vulnerability Reporting:** Navigate to the **Security** tab of this repository, select **Security advisories**, and click **Report a vulnerability**.
2. **Direct Contact:** Reach out directly via [LinkedIn](https://www.linkedin.com/in/muhammad-aqib-tayyab-815499348/).

### What to Include in Your Report
To help resolve the issue quickly, please include:
* A description of the vulnerability and its potential impact.
* Exact steps to reproduce the issue.
* The OS and Python version you are running.
* Any relevant logs or screenshots.

### Response Timeline
I review reports regularly and will acknowledge receipt of your vulnerability report within 48-72 hours. Once verified, I will work on a patch and notify you before the fix is publicly released.
